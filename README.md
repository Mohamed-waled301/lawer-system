# نظام إدارة مكتب المحاماة والاستشارات القانونية
### Law Office Management System (Next.js + Electron Ready)

نظام متكامل ورسمي لإدارة مكاتب وشركات المحاماة، مبني بأحدث تقنيات الويب **Next.js 14 (App Router)** ومجهز معمارياً للتحويل إلى تطبيق سطح مكتب **Electron** مباشرة.

---

## 🏛️ الميزات والمواصفات التصميمية
- **الهوية البصرية:** تصميم رسمي ومحافظ، يعتمد على الألوان الرسمية (أبيض / رمادي فاتح / كحلي داكن Dark Navy)، مع خط **Cairo** المعتمد للنصوص القانونية، وتصميم RTL من اليمين لليسار مخصص للبيئة العربية بدون حركات أو بهرجة بصرية زائدة.
- **قاعدة البيانات:** **Prisma + SQLite** محلي، متوافق مع نظام الملفات المحلي وسطح المكتب وقابل للتحويل إلى **PostgreSQL** بمجرد تعديل سطر واحد في `schema.prisma`.
- **فصل الصلاحيات والأمان:**
  - **مدير النظام (Admin):** صلاحيات كاملة، رؤية التقارير والمؤشرات المالية، حذف وأرشفة السجلات، وتصدير/استعادة النسخ الاحتياطية.
  - **الموظف والسكرتارية (Employee):** تسجيل الجلسات، بيانات الموكلين، والاستشارات، مع حظر كامل لرؤية التقارير المالية أو الحذف (مفروض برمجياً على مستوى السيرفر).
- **أرشفة المستندات:** حفظ الملفات الورقية الممسوحة ضوئياً وصور الإيصالات خارج مجلد `public`، وتقديمها عبر Route Handler مشفر ومحمي بالجلسة (`/api/documents/[id]`).
- **المطبوعات الرسمية:** صفحات طباعة مخصصة بنسق A4 مع ترويسة وهوية المكتب (إيصالات استلام نقدية، إيصال استشارة، ملف الموكل الشامل، تقرير ملف القضية).
- **جاهزية المسح الضوئي (ScannerService):** واجهة مجهزة تدعم الرفع المباشر عبر الويب وتتكامل مع بروتوكول **NAPS2 CLI / WIA** في تطبيق Electron.

## 🚀 التشغيل والتثبيت (Setup & Run)

### 1. تثبيت الحزم وتوليد قاعدة البيانات:
```bash
npm install
npm run db:generate
npm run db:push
npm run db:seed
```

### 2. تشغيل النظام في وضع التطوير (Web):
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 3. بيانات الدخول التجريبية (Demo Accounts):
- **حساب المدير (Admin):**
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`
- **حساب الموظف والسكرتارية (Employee):**
  - اسم المستخدم: `employee`
  - كلمة المرور: `emp123`

## 🖥️ خطوات التحويل إلى تطبيق سطح المكتب (Electron Desktop App)

تم تصميم النظام بمعمارية جاهزة للتحويل الفوري:

1. **بناء Next.js في وضع Standalone:**
   تم ضبط `next.config.mjs` مسبقاً بخاصية `output: "standalone"`. عند تشغيل `npm run build` يتم إنتاج خادم Node.js مستقل بالكامل داخل `.next/standalone`.
2. **تشغيل السيرفر داخل Main Process على Localhost:**
   يقوم ملف `electron/main.js` بتشغيل السيرفر تلقائياً على عنوان محلي عبر المنفذ الداخلي (مثال `http://127.0.0.1:34567`).
3. **توجيه قاعدة البيانات والملفات إلى مسار المستخدم `app.getPath('userData')`:**
   يقوم Electron بتهيئة المسارات تلقائياً لضمان حفظ بيانات القضايا في مجلد آمن لا يتأثر بتحديثات التطبيق:
   ```javascript
   process.env.DATABASE_URL = `file:${path.join(app.getPath('userData'), 'database', 'office.db')}`;
   process.env.UPLOADS_DIR = path.join(app.getPath('userData'), 'uploads');
   ```
4. **تكامل الماسح الضوئي (NAPS2 CLI):**
   يتصل التطبيق بماسحات USB/Network الضوئية عبر الأمر المباشر لـ NAPS2:
   ```bash
   naps2.console.exe -o "outputPath.pdf" --dpi 300
   ```
5. **إنتاج ملف التثبيت المكتبي (Installer):**
   يمكن تجميع البرنامج كملف تنفيذي (`.exe`) لنظام ويندوز عبر حزمة `electron-builder` باستخدام الإعدادات الجاهزة في `electron-builder.json`.
